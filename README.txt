HOW TO RUN
----------
1. Extract the ZIP file.
2. Open index.html in your browser.
3. The website works locally; no server or installation is required.

ADD YOUR PHOTOS
---------------
The four photos for the gallery are already included in the images folder.
To replace them, update the image paths in index.html to match your filenames.

ADD YOUR SONG
-------------
The song provided for the website is already included in the audio folder.
